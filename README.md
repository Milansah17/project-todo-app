# Todo List App

A simple todo list app built with HTML, CSS and JavaScript to manage daily tasks.

## Features
- Add new tasks
- Mark tasks as completed
- Delete tasks

## Tech used
- HTML
- CSS
- JavaScript

## Live demo
https://milansah17.github.io/todo-list-app/

## How to run locally
1. Download or clone this repository.
2. Open `index.html` in any browser.

## What I learned
- Handling user input and DOM manipulation with JavaScript
- Updating the page dynamically when tasks change
- Structuring a small project with separate HTML, CSS and JS files
